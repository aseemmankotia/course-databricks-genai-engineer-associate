## Chapter 4: Multi-Stage Chains and Prompt Engineering — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | LangChain method to log a SequentialChain in MLflow? | mlflow.langchain.log_model(chain, artifact_path, input_example=example). Exam tip: Use mlflow.langchain namespace, NOT mlflow.pyfunc or generic mlflow.log_model. Logs the entire chain as a versioned artifact. |
| 2 | LangChain class to use Databricks Foundation Model API endpoints? | ChatDatabricks(endpoint='databricks-model-name', max_tokens=512). Exam tip: Use ChatDatabricks for chat models, not OpenAI or generic LLM classes. The endpoint parameter specifies the serving endpoint name. |
| 3 | Recommended number of examples for few-shot prompting in exam scenarios? | 2-3 example input-output pairs. Exam tip: The exam emphasizes 2-3 as the practical range (not 1, not 10+). More examples increase cost/latency without proportional accuracy gains for most tasks. |
| 4 | When to use SequentialChain vs RetrievalQA? | SequentialChain: multi-step processing (extract → transform → generate). RetrievalQA: question answering with document retrieval (RAG pattern). Exam tip: RetrievalQA = always retrieval-based. SequentialChain = any multi-step workflow. |
| 5 | Chain-of-thought prompting instruction phrase? | 'Let's think step by step' or 'Show your reasoning before the answer'. Exam tip: Chain-of-thought = instructing the model to show intermediate reasoning steps. Used for complex reasoning tasks (math, logic). |
| 6 | How to combine few-shot and chain-of-thought prompting? | Provide 2-3 examples where each example includes the input, the step-by-step reasoning process, and the final answer. Exam tip: The examples themselves demonstrate the reasoning pattern, not just the final output. |
| 7 | LangChain chain type for multi-step workflows on Databricks? | SequentialChain - chains multiple steps where output of one becomes input to next. Exam tip: SequentialChain logs as a single MLflow artifact, enabling versioning of the complete workflow. |
| 8 | LangChain retriever for Databricks Vector Search? | DatabricksVectorSearch configured as a retriever in RetrievalQA chain. Exam tip: RetrievalQA chain combines a retriever (Vector Search) + LLM (Foundation Model API) for RAG patterns. |
| 9 | When does chain-of-thought improve LLM accuracy most? | Multi-step reasoning tasks: math word problems, logical deduction, complex classification requiring explanation. Exam tip: Chain-of-thought helps when the model needs to 'show its work', not for simple classification or generation. |
| 10 | PromptTemplate vs ChatPromptTemplate in LangChain? | PromptTemplate: single text prompt. ChatPromptTemplate: structured messages (system, user, assistant). Exam tip: Use ChatPromptTemplate with ChatDatabricks for chat models; PromptTemplate for completion models. |
| 11 | What does mlflow.langchain.log_model capture? | The complete chain (prompts, LLM configs, steps), dependencies (LangChain version), and metadata. Exam tip: Logging a SequentialChain logs the entire multi-step workflow as one reproducible artifact. |
| 12 | Few-shot prompting use case on the exam? | Classification, extraction, formatting tasks where showing 2-3 examples clarifies the desired output structure. Exam tip: Few-shot = providing example input-output pairs in the prompt. Not for complex reasoning (use chain-of-thought). |
