## Chapter 8: Governance with Unity Catalog and AI Guardrails — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Unity Catalog: permission needed to query a Vector Search index? | EXECUTE on the Vector Search index. This is independent of underlying Delta table permissions - users can query embeddings without SELECT on source table. Exam tip: Vector Search permissions separate from table permissions. |
| 2 | Databricks AI Guardrails: four main filter categories? | 1) toxicity (hate speech, profanity), 2) pii (SSN, email, credit cards), 3) prompt_injection (jailbreaks, instruction manipulation), 4) custom filters (regex, keyword lists). Exam tip: prompt_injection is the jailbreak detector. |
| 3 | Llama Guard category S3 detects what content type? | Sexual Content (explicit sexual descriptions). Full taxonomy: S1=Violence, S2=Hate, S3=Sexual, S4=Guns, S5=Regulated Substances, S6=Self-Harm, S7=Criminal Planning. Exam tip: S3=Sexual, S6=Self-Harm (commonly confused). |
| 4 | Unity Catalog system table for model access audit logs? | system.access.audit - logs EXECUTE events on models with principal_email, request_timestamp, action_name. Query: SELECT * FROM system.access.audit WHERE action_name='EXECUTE' AND object_type='MODEL'. Exam tip: audit = access events, not billing. |
| 5 | GRANT statement to allow model inference only (no modify)? | GRANT EXECUTE ON MODEL catalog.schema.model_name TO principal; (EXECUTE = inference, not MODIFY/DELETE). Exam tip: EXECUTE for models, SELECT for tables - different privileges. |
| 6 | Unity Catalog Data Lineage tracks which GenAI object relationships? | Delta table → Vector Search index → Registered model → Model Serving endpoint. Shows automatic dependency graph: which tables feed indexes, which indexes feed models. Exam tip: Lineage = dependencies, Audit = access logs (different features). |
| 7 | Databricks AI Guardrails: where are filters configured? | Model Serving endpoint configuration under AI Guardrails section. Enable per-endpoint: pii detection, prompt injection, toxicity filters. Applied at inference time before/after LLM call. Exam tip: Configured at endpoint level, not cluster or notebook. |
| 8 | PII detection in Guardrails: what happens when PII found in prompt? | Request is BLOCKED before reaching LLM (returns error to user). Alternative: mask/redact PII and send masked text (configurable). Default behavior: block. Exam tip: Guardrails blocks by default, not auto-mask. |
| 9 | Llama Guard vs Databricks AI Guardrails: key difference? | Llama Guard: open-source safety model (7B params) for content categories (violence, hate, sexual, self-harm). Guardrails: Databricks managed service for PII, toxicity, prompt injection. Use both together: Guardrails for PII/jailbreaks, Llama Guard for content safety. Exam tip: Guardrails=PII focus, Llama Guard=content safety focus. |
| 10 | Foundation model licensing: authoritative source for commercial use terms? | Model card (Hugging Face repo, model provider site) License and Intended Use sections. Shows training data provenance, commercial restrictions (e.g., Apache 2.0 vs proprietary). Exam tip: Model card = legal source, not Unity Catalog metadata (user-entered). |
| 11 | Unity Catalog: can user query Vector Search index without SELECT on source Delta table? | YES - Vector Search index permissions independent of underlying table. EXECUTE on index allows queries without SELECT on table. Enables data separation: query embeddings without seeing raw data. Exam tip: Index permissions ≠ table permissions (commonly tested). |
| 12 | Service principal permission syntax in Unity Catalog GRANT statement? | Use backticks with app ID: GRANT EXECUTE ON MODEL my_model TO `a1b2c3d4-e5f6-7890-abcd-ef1234567890`; (app ID from Azure/AWS IAM, not email). Exam tip: Backticks required, app ID format (UUID), not email. |
