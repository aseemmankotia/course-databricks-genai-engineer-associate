## Chapter 10: Full Practice Exam and Test-Taking Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Databricks GenAI Engineer exam format: number of questions, time limit, passing score? | 45 scored questions, 90 minutes, 70/100 passing score (~31-32 correct answers needed). Exam tip: 2 minutes per question pace, aim to finish with 10 minutes to spare for review |
| 2 | Domain weighting for Databricks GenAI Engineer exam (list all 6 domains with percentages)? | 1. Application Development 30% \| 2. Deployment & Operations 22% \| 3. Design & Architecture 14% \| 4. Data Preparation 14% \| 5. Evaluation & Governance 12% \| 6. Governance & Security 8%. Exam tip: focus study time proportional to weights |
| 3 | Common Vector Search embedding dimensions tested on exam? | 384 (smaller models), 768 (BERT-base, sentence-transformers), 1024 (larger sentence transformers), 1536 (OpenAI text-embedding-ada-002). Exam trap: dimension must match between embedding model and index configuration |
| 4 | When to choose Delta Sync vs Direct Vector Access index? | Delta Sync: auto-sync from Delta table, real-time updates, Unity Catalog governed (use for production RAG). Direct Vector Access: manual control, external vector sources, no Delta table required (use for migration/external data). Exam tests: which meets 'real-time updates' requirement |
| 5 | Model Serving compute size options and when to use each? | CPU_SMALL (embeddings, simple models), GPU_SMALL (7B-13B LLMs, low concurrency), GPU_MEDIUM (13B-34B LLMs, high concurrency), GPU_LARGE (70B+ LLMs). Exam tip: scenarios test cost vs latency trade-off |
| 6 | MLflow flavor names required for Model Serving deployment? | transformers, sentence_transformers, langchain, openai, pyfunc (custom). Exam trap: model must be logged with a recognized flavor to deploy; plain .pkl file without flavor fails deployment |
| 7 | Unity Catalog permission types for Vector Search index (minimum for query access)? | USAGE on catalog and schema (navigate namespace), SELECT on underlying Delta table (read data), USAGE on index (query). Exam trap: forgetting index-level permission—table SELECT alone is insufficient |
| 8 | Exam scenario: 'must meet latency requirement of 200ms'—what deployment trap to avoid? | Avoid min_instances=0 (cold start is 30-60 sec). Use min_instances=1+ to ensure warm endpoint. Exam tests: identifying cold start as latency issue when requirements specify sub-second response |
| 9 | Exam scenario: minority class problem—precision high (0.95), recall low (0.45). What to optimize? | Optimize recall (increase sensitivity to minority class). Use: class weights, oversampling/SMOTE, or adjust decision threshold downward. Exam trap: focusing on already-high precision or overall accuracy |
| 10 | Common exam trap: 'requires Unity Catalog governance'—which solution is WRONG? | WRONG: external vector database with external location (external location only provides storage access, not query-level permissions or lineage). RIGHT: Delta table + Vector Search with Unity Catalog (native governance). Exam tests this distinction frequently |
| 11 | Time management: 15 questions left, 30 min remaining, 5 flagged for review. What order? | Answer all 10 unanswered questions first (2 min each = 20 min), then review 5 flagged questions (10 min). Rule: unanswered = 0 points guaranteed; flagged might be correct. Always answer all questions before reviewing |
| 12 | Exam scenario: fine-tuning data has 60% irrelevant examples, 15% target task examples. Best strategy? | Filter to only target task examples (quality > quantity), augment using paraphrasing/backtranslation to increase volume. Exam trap: 'maximize training data volume' by including irrelevant examples (causes model to learn wrong behavior) |
