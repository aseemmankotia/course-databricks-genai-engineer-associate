# Chapter 3 Lab: Building RAG Applications with Vector Search

**Estimated time:** 25 minutes

## Exercise

Lab: Build a simple RAG pipeline: query Vector Search index with a user question, retrieve top-5 chunks, construct a prompt template that includes chunks, call Databricks Foundation Model API (DBRX), display answer with source citations

## Key takeaway

Vector Search similarity_search retrieves chunks; prompt templates inject chunks and ground the model; similarity thresholds filter noise; explicit 'I don't know' instructions prevent hallucination.
