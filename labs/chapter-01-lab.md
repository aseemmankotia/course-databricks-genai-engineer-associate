# Chapter 1 Lab: Designing GenAI Applications on Databricks

**Estimated time:** 15 minutes

## Exercise

Decision tree exercise: given 3 business scenarios, select the correct approach (RAG, fine-tuning, agent) and justify with Databricks capabilities

## Key takeaway

The exam tests design trade-offs, not code—know when RAG beats fine-tuning (fresh data, lower cost), when to add rerankers (precision over recall), and which guardrails match which tools.
